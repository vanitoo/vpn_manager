# Roadmap

План развития Warp Private Network. Порядок задач может меняться по результатам эксплуатации.

## 0.8.x — Stabilization

- довести экран аккаунта и историю платежей до завершённого UX;
- решить, нужен ли полноценный внутренний баланс или оставить его информационным;
- улучшить диагностику Remnawave 3.x и сетевых проблем;
- доработать HelpDesk: поиск, фильтры, повторное открытие и быстрые ответы;
- усилить защиту от дублирующих действий оплаты и продления;
- продолжить упрощение пользовательского подключения через Happ.

## 0.9 — Commercial tools

- полноценный кошелёк/баланс с журналом операций, если он будет нужен бизнес-модели;
- промокоды;
- реферальная система;
- гибкие пробные периоды;
- скидки и индивидуальные тарифы;
- расширенная аналитика платежей и продлений;
- уведомления о неуспешных платежах;
- история административных действий.

## 1.0 — Stable release

- стабильная и документированная схема конфигурации;
- последовательные миграции базы данных;
- автоматические тесты критических сценариев;
- проверяемое обновление с предыдущих версий;
- процесс релиза и отката;
- production checklist;
- аудит безопасности;
- зафиксированные гарантии совместимости Remnawave API.

## После 1.0

- PostgreSQL;
- несколько экземпляров бота;
- распределённые блокировки;
- REST API при реальной необходимости;
- отдельный операторский интерфейс, если Telegram Topics перестанет хватать;
- мультиязычный интерфейс;
- расширенная observability: метрики, трассировка, алерты;
- дополнительные продуктовые модули вне VPN.

## Не входит в ближайший план

- собственная реализация VPN-протоколов;
- замена Remnawave собственной полноценной панелью;
- обязательный публичный веб-кабинет клиента;
- хранение приватных ключей пользователей в Telegram-боте.
